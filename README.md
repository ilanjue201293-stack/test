# RBX Analytics

Dashboard d'analyse approfondie des expériences Roblox, prêt pour Vercel.

## Fonctionnalités

- Recherche d'une expérience par nom, Universe ID ou URL Roblox
- Joueurs en ligne (CCU)
- Visites totales
- Favoris
- Likes / dislikes / like ratio
- Taille maximale des serveurs
- Prix et prix des serveurs privés quand disponibles
- Créateur, genre, dates de création et de mise à jour
- Ratios avancés : favoris/visites, joueurs/visites, visites/CCU
- Estimation du nombre de serveurs actifs à partir du CCU et de la capacité
- Graphiques Recharts
- Historique local des mesures observées dans le navigateur
- Onglet données brutes
- Proxy Next.js côté serveur vers les API publiques Roblox

## Déploiement Vercel

Importe ce dépôt dans Vercel. Aucun secret n'est nécessaire pour les endpoints publics utilisés par le dashboard.

Les données viennent des API publiques Roblox et peuvent changer selon leurs disponibilités, limites et évolutions.
